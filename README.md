# ☕ Álibi — Cafeteria & Livraria

Landing page desenvolvida para a cafeteria e livraria **Álibi**. O site apresenta o espaço, o cardápio com um carrossel dinâmico em JavaScript, a seleção de livros e a seção de reservas.

## 🛠️ Tecnologias
- HTML5
- CSS3 (Flexbox e Grid)
- JavaScript (ES6+)

## 💻 Como visualizar
Basta abrir o arquivo `index.html` em qualquer navegador.
